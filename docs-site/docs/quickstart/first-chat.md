# Первый чат

После запуска GigaAgent веб-интерфейс открывается, но обычный чат требует выбранной языковой модели. Если модель не настроена, сообщение может завершиться ошибкой конфигурации.

## 1. Войдите в интерфейс

Откройте:

```text
http://localhost:9090
```

Для чистой локальной установки используйте начальные данные администратора:

- `admin@example.com`
- `giga_agent_admin`

## 2. Добавьте подключение

Откройте **Настройки → Подключения** и добавьте подключение к провайдеру моделей. Подключение хранит параметры доступа: ключи, адреса и другие настройки провайдера.

Для локального запуска не обязательно заранее заполнять `.env`: ключ GigaChat, OpenAI-совместимого провайдера, DeepSeek и похожие параметры можно ввести прямо в форме подключения. Переменные окружения нужны, если вы хотите управлять секретами вне интерфейса или готовите общий сервер.

Какие поля нужны, зависит от выбранного провайдера. Если провайдер требует секретный ключ, храните его как секрет и не вставляйте в документацию, снимки экрана или переписку.

## 3. Добавьте языковую модель

Откройте **Настройки → Языковые модели (LLM)** и создайте запись модели, связанную с подключением. Укажите модель, которую должен использовать агент.

После создания модели откройте **Настройки → Общие** и выберите её в поле **Модель по умолчанию**.

## 4. Отправьте короткое сообщение

Вернитесь в чат и отправьте простой запрос, например:

```text
Кратко объясни, что ты умеешь делать в этой установке.
```

Если ответ пришёл потоком сообщений, базовая настройка работает.

## Если ответа нет

Проверьте:

1. Подключение сохранено без ошибок.
2. Языковая модель создана и выбрана как модель по умолчанию.
3. У провайдера действующий ключ доступа.
4. Сервер запущен и веб-интерфейс видит адрес `/api`.
5. В журнале запуска нет ошибок авторизации или недоступности провайдера.

## Что настроить после первого сообщения

| Задача | Что включить | Где описано |
|---|---|---|
| Работа с документами через RAG | Векторные представления и, при необходимости, Qdrant. | [RAG](../user-guide/rag.md), [Работа с файлами](../user-guide/files-and-artifacts.md) |
| Долговременная память | Векторные представления пользователя. | [Память](../user-guide/memory.md) |
| Выполнение кода и команд | Изолированную среду выполнения. | [Инструменты](../user-guide/tools.md), [Изолированная среда и безопасность](../operations/sandbox-security.md) |
| Генерация изображений | Провайдер генерации изображений. | [Изображения](../user-guide/images.md) |
| Поиск в интернете | Провайдер поиска. | [Внешние сервисы](../user-guide/external-services.md) |
| GitHub, VK, погода, субагенты | Соответствующие секреты в настройках агента. | [Внешние сервисы](../user-guide/external-services.md), [Субагенты](../developer/subagents.md) |
