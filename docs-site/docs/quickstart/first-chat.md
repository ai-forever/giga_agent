# Первый чат

После запуска GigaAgent веб-интерфейс открывается, но обычный чат требует выбранной языковой модели. Если модель не настроена, сообщение может завершиться ошибкой конфигурации.

## 1. Войдите в интерфейс

Откройте:

```text
http://localhost:9090
```

Для чистой локальной установки используйте начальные данные администратора:

- `admin@example.com`
- `giga_agent_admin`

## 2. Добавьте коннектор

Откройте **Настройки → Коннекторы** и добавьте подключение к провайдеру моделей. Коннектор хранит параметры доступа: ключи, адреса и другие настройки провайдера.

Для локального запуска не обязательно заранее заполнять `.env`: ключ GigaChat, OpenAI-совместимого провайдера, DeepSeek и похожие параметры можно ввести прямо в форме коннектора. Переменные окружения нужны, если вы хотите управлять секретами вне интерфейса или готовите общий сервер.

Какие поля нужны, зависит от выбранного провайдера. Если провайдер требует секретный ключ, храните его как секрет и не вставляйте в документацию, снимки экрана или переписку.

## 3. Добавьте языковую модель

Откройте **Настройки → Языковые модели (LLM)** и создайте запись модели, связанную с коннектором. Укажите модель, которую должен использовать агент.

После создания модели откройте **Настройки → Общие** и выберите её в поле **Модель по умолчанию**.

## 4. Отправьте короткое сообщение

Вернитесь в чат и отправьте простой запрос, например:

```text
Кратко объясни, что ты умеешь делать в этой установке.
```

Если ответ пришёл потоком сообщений, базовая настройка работает.

## Если ответа нет

Проверьте:

1. Коннектор сохранён без ошибок.
2. Языковая модель создана и выбрана как модель по умолчанию.
3. У провайдера действующий ключ доступа.
4. Сервер запущен и веб-интерфейс видит адрес `/api`.
5. В журнале запуска нет ошибок авторизации или недоступности провайдера.

## Что настроить после первого сообщения

| Задача | Что включить |
|---|---|
| Работа с документами через RAG | Векторные представления и, при необходимости, Qdrant. |
| Долговременная память | Векторные представления пользователя. |
| Выполнение кода и команд | Изолированную среду выполнения. |
| Генерация изображений | Провайдер генерации изображений. |
| Поиск в интернете | Провайдер поиска. |
| GitHub, VK, погода, субагенты | Соответствующие секреты в настройках агента. |

Подробная таблица есть в разделе [Возможности и требования](../user-guide/capabilities.md).
