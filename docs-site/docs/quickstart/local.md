# Быстрый старт локально

:::info Current/main
Эта инструкция предназначена для текущей ветки `main`. Если нужна установка опубликованного пакета из PyPI, переключитесь на версию **0.1.9 (PyPI)**.
:::

Ниже — минимальный путь от пустой папки до открытого веб-интерфейса GigaAgent из текущего состояния репозитория.

## Требования

- Python 3.11+; для воспроизводимого локального запуска рекомендуется Python 3.12.
- `uv` для отдельного окружения. Можно использовать и `pip`, но `uv` обычно быстрее и удобнее.
- Git для получения исходного кода.
- Свободный локальный порт `9090`.

## Запуск за несколько минут

```bash
git clone https://github.com/trashchenkov/giga_agent.git
cd giga_agent
uv venv --python python3.12 .venv
source .venv/bin/activate
uv pip install -e "backend[jupyter]"
giga_agent dev
```

Откройте:

```text
http://localhost:9090
```

Первый запуск может занять заметное время: команда загружает зависимости, подготавливает локальный секретный ключ, проверяет миграции и поднимает сервер разработки.

Файл `.env` для первого локального запуска можно не создавать. Ключи провайдеров моделей и другие прикладные секреты можно добавить позже в веб-интерфейсе.

## Первый вход

На чистой локальной базе создаётся пользователь администратора:

| Поле | Значение |
|---|---|
| Почта | `admin@example.com` |
| Пароль | `giga_agent_admin` |

Для локальной демонстрации этого достаточно. Для общего сервера пароль и секретный ключ нужно заменить; см. [Совместный сервер](../operations/shared-server.md).

## Проверка миграций

Обычно `giga_agent dev` запускает миграции сам. Если нужна явная проверка:

```bash
giga_agent migrate
giga_agent check
```

Если сначала выполнить `giga_agent check` на пустой базе, команда может сообщить, что миграции ещё не применены. Это ожидаемо; выполните `giga_agent migrate`, затем повторите проверку.

## Важные адреса

| Адрес | Назначение |
|---|---|
| `http://localhost:9090/` | Веб-интерфейс. |
| `http://localhost:9090/app-config.js` | Рабочая конфигурация интерфейса. |
| `http://localhost:9090/api/info` | Служебная информация сервера LangGraph. |
| `http://localhost:9090/api/agent/...` | Маршруты GigaAgent. |

Для обычного пользователя достаточно открыть веб-интерфейс. Прямые HTTP-запросы нужны при диагностике или интеграции.
