# Задачи по расписанию

Агент выполняет задачи в фоне по расписанию: разово в назначенное время («завтра в 9 сделай сводку погоды») или периодически («каждый понедельник собирай итоги недели»). Задача формулируется обычной просьбой в чате — агент сам вызовет нужный инструмент и подтвердит постановку.

## Как поставить задачу

Напишите агенту, что и когда выполнить. Время задаётся датой («29 июня в 9:00») или периодичностью («каждый день в 9»); внутри это разовые задачи с датой запуска и периодические с расписанием cron. Задаче можно дать короткое название.

Результат выполнения приходит сообщением в подключённый [канал](./channels.md) — например, в ваш Telegram. Получателей можно выбрать при постановке из одобренных контактов каналов; без явного выбора результат уходит получателям по умолчанию. Если у владельца задачи нет ни одного получателя, задача выполнится, а доставить результат будет некуда — подключите канал заранее.

## Управление задачами

Список задач доступен двумя путями:

- в веб-интерфейсе — пункт **Планировщик** в меню пользователя открывает страницу **Запланированные задачи**: здесь задачи можно просмотреть и удалить;
- в чате — попросите агента показать, изменить или отменить задачи. Изменяются текст задачи, время, название и получатели.

В групповом чате Telegram задачи живут по правилам чата: созданная в чате задача присылает результат в этот же чат, а изменять и отменять её может только автор.

## Что задача умеет

Фоновая задача — это полноценный запуск агента с вашим текстом: она может искать, считать, обращаться к подключённым сервисам. Задача наследует область памяти диалога, в котором была создана, поэтому агент в фоне помнит контекст, доступный этому диалогу.
