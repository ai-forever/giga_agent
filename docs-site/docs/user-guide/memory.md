# Память

Память хранит устойчивые сведения, которые агент может использовать в следующих диалогах: предпочтения пользователя, рабочий контекст, заметки по проектам и другие повторно используемые факты.

## Что нужно настроить

Для полноценной работы памяти нужны:

- выбранная языковая модель;
- выбранная модель векторных представлений;
- доступное хранилище векторов;
- права пользователя на свои записи памяти.

Если модель векторных представлений не выбрана или хранилище векторов недоступно, поиск по памяти может не работать.

## Как пользоваться

1. Откройте раздел **Память** в интерфейсе.
2. Создайте или проверьте записи памяти.
3. Убедитесь, что у пользователя выбраны векторные представления.
4. Вернитесь в чат и задайте вопрос, для которого нужен сохранённый контекст.

Агент также может работать с файлами памяти через специальные пути вида `/memories/...`, если соответствующие инструменты доступны в текущем диалоге.

## Практические ограничения

- Не сохраняйте в память секреты, пароли и ключи доступа.
- Для общего сервера заранее определите, какие данные пользователи могут сохранять.
- Если память не используется в ответе, проверьте выбранные векторные представления и доступность хранилища векторов.
