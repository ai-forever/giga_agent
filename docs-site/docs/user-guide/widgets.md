# Виджеты в чате

:::info[Документация текущего состояния]
Эта страница описывает текущую ветку `main` репозитория GigaAgent. Для стабильной документации PyPI-пакета `giga-agent==0.1.9` выберите версию **0.1.9 (PyPI)** в переключателе версий.
:::

Результаты части инструментов агент показывает интерактивными карточками прямо в ответе. Виджет удобнее пересказа: данные видны сразу, а действия выполняются без лишних сообщений в чате.

## Какие виджеты есть

**Входящие письма.** Список писем Яндекс.Почты: отправитель, тема, дата. Письмо раскрывается по нажатию, и его текст подгружается сразу, без обращения к модели. Вёрстка письма показывается в изолированной рамке: скрипты в ней запрещены, ссылки открываются в новой вкладке.

**Повестка календаря.** События ближайших дней списком.

**Сетка месяца.** Календарь на месяц с событиями по дням.

**Обозреватель файлов.** Содержимое папки Яндекс.Диска. По папкам можно переходить прямо в виджете, у файлов есть кнопки публикации по открытой ссылке и снятия публикации.

## Как они работают

Виджет появляется автоматически, когда инструмент возвращает подходящие данные: попросите агента показать входящие, расписание на неделю или содержимое папки — и получите карточку. Действия внутри виджета (раскрыть письмо, перейти в папку) выполняются напрямую через серверные маршруты. Действия с последствиями — отправка письма, удаление — остаются за агентом и проходят обычный путь [подтверждения вызова инструмента](./yandex-services.md#подтверждения-действий).

В Telegram-канале виджеты недоступны: там агент отвечает текстом.

Для разработчиков: соответствие «данные → виджет» задаёт реестр `front/src/components/widgets/registry.ts`, устройство описано в [Архитектуре](../developer/architecture.md).
