# Каналы

Канал — способ общаться с агентом вне веб-интерфейса. Сейчас поддерживается Telegram: агент отвечает в личных и групповых чатах через подключённого бота. Устройство каналов расширяемое, тип канала выбирается при создании.

## Настройка

Каналы настраиваются в **Настройки → Каналы**. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте его токен, затем нажмите **Создать**, выберите тип канала и укажите токен. После запуска бот начинает принимать сообщения.

## Контакты и доступ

Каждый, кто напишет боту, появляется в списке контактов канала — и до одобрения бот его сообщения игнорирует. Одобрите контакт в настройках канала, чтобы открыть человеку доступ к агенту. Там же контакт можно назначить получателем по умолчанию для [задач по расписанию](./scheduler.md) или удалить — после удаления человеку придётся написать боту заново.

## Чем канал отличается от веб-чата

- Агент в Telegram отвечает текстом; [виджеты](./widgets.md) доступны только в веб-интерфейсе.
- Вызовы инструментов в Telegram выполняются без подтверждений — диалог там всегда автономный. Это касается и необратимых действий вроде отправки письма: учитывайте это, одобряя контактам доступ к агенту с подключёнными [сервисами Яндекса](./yandex-services.md).
- В групповом чате агент видит контекст группы; задачи по расписанию, созданные в чате, присылают результат в этот же чат.
