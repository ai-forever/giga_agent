# Сервисы Яндекса

:::info[Документация текущего состояния]
Эта страница описывает текущую ветку `main` репозитория GigaAgent. Для стабильной документации PyPI-пакета `giga-agent==0.1.9` выберите версию **0.1.9 (PyPI)** в переключателе версий.
:::

Агент умеет читать и отправлять почту, вести календарь и работать с файлами на Диске от имени вашей учётной записи Яндекса. Сервисы включаются по одному: каждый подключается через [каталог коннекторов](./connectors.md) по OAuth, доступ можно отозвать в любой момент на вкладке «Подключённые».

Предусловие: администратор сервера заранее указывает данные OAuth-приложения Яндекса в [конфигурации](../operations/configuration.md). Это разовая настройка приложения; пользователи после неё подключаются кнопкой.

## Яндекс.Почта

Агент ищет письма по папке, отправителю и теме («покажи последние письма от банка»), читает письмо целиком по просьбе и отправляет письма с вашего ящика. Список писем показывается карточкой входящих прямо в чате; подробности о таких карточках — на странице [Виджеты](./widgets.md).

Отправка письма выполняется только по явной просьбе и проходит через подтверждение вызова инструмента.

## Яндекс.Календарь

Агент показывает события на ближайшие дни («что у меня на неделе»), выводит сетку месяца, создаёт события с названием, временем начала и конца, удаляет события. Повестка и сетка месяца показываются виджетами календаря в чате.

## Яндекс.Диск

Агент просматривает папки, читает текстовые файлы, создаёт папки, сохраняет текст в файл, публикует файл по открытой ссылке и снимает публикацию, удаляет файлы. Содержимое папок показывается обозревателем файлов в чате.

## Подтверждения действий

Пока автономный режим выключен, каждый вызов инструмента ждёт вашего подтверждения — это относится и к отправке писем, созданию и удалению событий, удалению файлов. В автономном режиме подтверждение вызовов отключено: агент выполняет действия сразу, включая необратимые. Включая автономный режим в диалоге с подключённой почтой или Диском, учитывайте это.

## Если сервис перестал отвечать

Сохранённый доступ со временем может устареть или быть отозванным со стороны Яндекса. Карточка сервиса на вкладке «Подключённые» покажет состояние «Нужна повторная авторизация» — нажмите «Авторизоваться» и войдите заново. Токены при обычной работе продлеваются автоматически.
