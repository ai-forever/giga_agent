# RAG

RAG — это поиск по вашим документам перед ответом модели. Пользователь создаёт коллекции, загружает документы и выбирает активные коллекции в чате. После этого агент может искать по ним, если настроены векторные представления и хранилище векторов.

## Что нужно настроить

Для работы RAG нужны:

- текущий пользователь;
- выбранная модель векторных представлений;
- доступное хранилище векторов, например Qdrant;
- права на коллекции и документы.

Если векторные представления не настроены, RAG-маршруты и инструменты могут отвечать ошибкой конфигурации.

## Основные маршруты

Для `giga_agent dev` внешний префикс — `/api/agent`, поэтому RAG-маршруты доступны под `/api/agent/rag`:

- `POST /collections` — создать коллекцию;
- `GET /collections` — список доступных коллекций;
- `GET /collections/{collection_id}` — сведения о коллекции;
- `PATCH /collections/{collection_id}` — обновить коллекцию;
- `DELETE /collections/{collection_id}` — удалить коллекцию;
- `POST /collections/{collection_id}/documents` — загрузить документы;
- `GET /collections/{collection_id}/documents` — список документов;
- `DELETE /collections/{collection_id}/documents/{document_id}` — удалить документ;
- `POST /collections/{collection_id}/documents/search` — поиск по документам.

## Как пользоваться

1. Настройте векторные представления в настройках пользователя.
2. Создайте коллекцию в разделе RAG.
3. Загрузите документы.
4. Выберите активные коллекции в чате.
5. Задайте вопрос; агент сможет искать по документам, если у пользователя есть права.

Если коллекция видна в интерфейсе, но поиск не работает, сначала проверьте настройки векторных представлений и доступность Qdrant.
