# Возможности и требования

GigaAgent состоит из базового веб-интерфейса и набора подключаемых возможностей. Часть функций доступна сразу после запуска, но большинство полезных сценариев требует настроенных провайдеров.

## Минимальная рабочая настройка

Для первого полезного ответа достаточно:

1. Создать подключение к провайдеру моделей.
2. Создать языковую модель на основе этого подключения.
3. Выбрать её как модель по умолчанию для пользователя.

После этого можно пользоваться обычным чатом.

## Настройки для работы с документами

Для RAG нужны:

- модель векторных представлений;
- доступное хранилище векторов;
- коллекция документов;
- права пользователя на чтение коллекции.

Если коллекция создана, но поиск не работает, сначала проверьте, выбраны ли векторные представления у пользователя.

## Настройки для выполнения кода

Инструменты выполнения кода и команд требуют изолированной среды. Это привилегированная возможность: она может читать и создавать файлы, запускать процессы и расходовать ресурсы машины.

Перед включением для других пользователей прочитайте [Изолированная среда и безопасность](../operations/sandbox-security.md).

## Настройки для общего сервера

Если сервер открывается не только на вашей машине, минимально проверьте:

- длинный случайный `GIGA_AGENT_SECRET_KEY`;
- смену начального пароля администратора;
- закрытый доступ к панели администратора;
- осторожную настройку изолированной среды;
- отсутствие секретов в документации, снимках экрана и журналах.

Подробнее см. [Совместный сервер](../operations/shared-server.md).
