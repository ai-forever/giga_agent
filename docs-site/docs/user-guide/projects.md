# Проекты

:::info[Документация текущего состояния]
Эта страница описывает текущую ветку `main` репозитория GigaAgent. В стабильном PyPI-пакете `giga-agent==0.1.9` проектов ещё нет.
:::

Проект — это способ объединить связанные диалоги вокруг общих инструкций и собственной базы знаний. Каждый диалог можно привязать к проекту, и тогда агент в этом диалоге получает инструкции проекта и, если она настроена, его базу знаний.

## Из чего состоит проект

| Поле | Назначение |
|---|---|
| Название | Имя проекта. Уникально в пределах одного пользователя. |
| Описание | Необязательный короткий текст о проекте. |
| Инструкции | Необязательный текст, который добавляется к системному промпту во всех диалогах проекта как дополнительный контекст. |
| База знаний | Необязательная коллекция RAG, привязанная к проекту. |

## Инструкции проекта

Если у проекта заданы инструкции, в каждом привязанном диалоге они подставляются в системный промпт отдельным блоком «Project context» поверх общего системного промпта. Это удобно, когда у группы диалогов общие правила, роль или контекст.

Инструкции применяются только к диалогам, привязанным к проекту. Обычные диалоги их не получают.

## База знаний проекта

У проекта может быть собственная коллекция RAG. Поведение при создании проекта:

- если у пользователя настроены [векторные представления](./rag.md), коллекция проекта создаётся автоматически;
- если векторные представления не настроены, проект сохраняется без базы знаний — её можно добавить позже, настроив векторные представления.

Подробнее о требованиях к RAG см. [RAG по документам](./rag.md).

## Как пользоваться

1. Создайте проект и при необходимости задайте инструкции.
2. Создайте диалог внутри проекта или привяжите к нему существующий.
3. Над полём ввода в таком диалоге показывается чип проекта.
4. Агент в этом диалоге учитывает инструкции проекта и его базу знаний.

В боковой панели проекты отображаются отдельной секцией с раскрывающимися папками; диалоги проекта не дублируются в общем списке диалогов.

:::note[Загрузка файлов в проект]
Чтобы загружать файлы в базу знаний проекта, нужны настроенные векторные представления, а для части сценариев — [изолированная среда](../operations/sandbox-security.md). Если загрузка недоступна, интерфейс подсказывает, что именно нужно настроить.
:::

## Основные маршруты

Для `giga_agent dev` внешний префикс — `/api/agent`, поэтому маршруты проектов доступны под `/api/agent/projects`:

- `GET /projects` — список проектов пользователя;
- `POST /projects` — создать проект;
- `GET /projects/{project_id}` — сведения о проекте;
- `PATCH /projects/{project_id}` — обновить проект;
- `DELETE /projects/{project_id}` — удалить проект.

Привязка диалога к проекту хранится в метаданных потока LangGraph (`project_id`).
