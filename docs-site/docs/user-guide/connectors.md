# Коннекторы

:::info[Документация текущего состояния]
Эта страница описывает текущую ветку `main` репозитория GigaAgent. Для стабильной документации PyPI-пакета `giga-agent==0.1.9` выберите версию **0.1.9 (PyPI)** в переключателе версий.
:::

Коннектор — внешний сервис, который добавляет агенту инструменты. Коннекторы бывают двух видов: серверы [MCP](https://modelcontextprotocol.io/) и встроенные интеграции — Яндекс.Почта, Яндекс.Календарь, Яндекс.Диск, VK. Управляются они в одном месте: в каталоге коннекторов.

## Где найти

Откройте меню «плюс» рядом с полем ввода сообщения и выберите пункт **Коннекторы**. В подменю видны уже подключённые сервисы с переключателями — так можно быстро убрать инструменты сервиса из диалога и вернуть их обратно. Пункт **Управление коннекторами** открывает окно каталога с двумя вкладками: **Каталог** и **Подключённые**.

## Каталог

Вкладка **Каталог** показывает карточки всех доступных сервисов: сначала встроенные интеграции, затем серверы MCP. Карточки ищутся по названию и описанию, фильтруются по категориям: «Российские», «Разработка», «Документация», «Поиск», «Покупки», «Путешествия» и другим.

В каталог серверов MCP текущей ветки `main` входят: ВкусВилл, Туту.ру, Bitrix24, GitHub, DeepWiki, Context7, Excalidraw, Hugging Face, Tavily Search, Sentry и Replicate. Состав каталога задаёт файл `modules/mcp/catalog.json`, поэтому список может меняться от сборки к сборке.

## Подключение сервиса

Порядок действий зависит от способа авторизации сервиса.

**Сервис с OAuth** (например, Яндекс.Почта). Нажмите кнопку подключения на карточке — откроется всплывающее окно авторизации сервиса. Подтвердите доступ, окно закроется, карточка отметится как подключённая. Токены доступа обновляются автоматически.

**Сервис с токеном** (например, VK или сервер MCP с Bearer-токеном). Первое нажатие раскрывает форму на карточке. Заполните запрошенные поля — у полей есть подсказки и ссылки на страницы, где взять ключ, — и подтвердите. Пустые обязательные поля форма не пропустит.

**Сервер MCP с OAuth.** Сервер сначала добавляется, затем сразу открывается окно авторизации.

Для интеграций Яндекса администратор заранее указывает данные OAuth-приложения в настройках сервера — см. [Конфигурацию](../operations/configuration.md). Пока приложение не настроено, карточки подскажут, как его включить.

## Свой коннектор

Кнопка **Свой коннектор** на вкладке «Каталог» добавляет произвольный сервер MCP: укажите название, адрес (`https://mcp.example.com/mcp`) и способ авторизации — без авторизации, Bearer-токен или OAuth. Для OAuth при необходимости задаётся область доступа.

## Вкладка «Подключённые»

Здесь собраны все подключённые коннекторы. Для каждого доступны:

- переключатель — временно убрать инструменты сервиса из диалогов;
- список доступных инструментов сервера — раскрывается на карточке;
- кнопка **Авторизоваться** — когда сервис просит повторную авторизацию;
- отключение — с подтверждением, связка с сервисом удаляется.

Состояние «Нужна повторная авторизация» означает, что сохранённый доступ устарел или отозван: нажмите **Авторизоваться** и пройдите вход в сервис заново.

## Как коннекторы работают в чате

Инструменты подключённых коннекторов агент использует наравне со встроенными. Учитывайте:

- набор инструментов зависит от того, какие коннекторы включены, поэтому может отличаться между диалогами;
- выключенный в меню чата сервис недоступен агенту в этом диалоге;
- права пользователя и правила выполнения инструментов проверяет серверная часть.

Результаты части инструментов интерфейс показывает наглядно — карточками писем, календарём, списком файлов. Для разработчиков устройство каталога описано в [Архитектуре](../developer/architecture.md).
