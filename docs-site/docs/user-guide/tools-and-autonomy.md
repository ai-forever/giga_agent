# Инструменты и автономность

В чате агент может вызывать инструменты: читать и создавать файлы, запускать код в изолированной среде, искать документы, обращаться к внешним сервисам или выполнять специализированные действия. Набор инструментов зависит от настроек пользователя.

## Что видит пользователь

- В ответе могут появляться вызовы инструментов и результаты их работы.
- Некоторые действия требуют отдельной настройки: изолированная среда, векторные представления, поиск, генерация изображений или внешний секрет.
- Если возможность не настроена, агент должен сообщить об ограничении, а не обещать выполнение.

## Служебные инструменты рассуждения

Для некоторых провайдеров серверная часть может добавить служебные инструменты:

- `think` — помогает модели структурировать сложную задачу;
- `multi_tool_use` — позволяет выполнять независимые вызовы инструментов параллельно.

Пользователю не нужно включать их вручную: доступность определяется настройками сервера и выбранной языковой модели.

## Автоматическое подтверждение

Флаг `auto_approve` относится к поведению диалога: агент может проходить часть шагов без дополнительного подтверждения. Это не отключает проверки прав, ограничения изолированной среды и серверные правила безопасности.

## Если инструмент недоступен

Проверьте в настройках:

1. выбрана ли языковая модель;
2. настроен ли нужный провайдер: изолированная среда, векторные представления, поиск или генерация изображений;
3. есть ли права на файл, коллекцию или другой ресурс;
4. не отключён ли соответствующий модуль для пользователя.

Описание для разработчиков о сборке инструментов находится в разделе [Инструменты](../developer/tools.md).
