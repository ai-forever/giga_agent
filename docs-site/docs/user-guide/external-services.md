# Внешние сервисы

Часть инструментов GigaAgent обращается к внешним сервисам. Они не включаются только фактом установки пакета: сначала нужно добавить провайдер или секрет пользователя.

## Поиск в интернете

Для поиска нужен провайдер поиска. В интерфейсе настройка находится в разделе **Настройки → Поиск**. Если провайдер требует ключ доступа, его можно указать в форме настройки провайдера.

После создания провайдера выберите его в **Настройки → Общие** как поисковый провайдер пользователя.

## VK и погода

Модуль погоды использует секрет пользователя `OWM_API_KEY` — он заполняется в **Настройки → Общие** в блоке секретов агента. Если поле не заполнено, инструмент недоступен.

VK подключается через [каталог коннекторов](./connectors.md) по токену. Прежний способ — секрет пользователя `VK_TOKEN` — продолжает работать.

## GitHub

GitHub подключается как сервер из [каталога коннекторов](./connectors.md): официальный сервер MCP с доступом к репозиториям, задачам и запросам на слияние. При подключении понадобится токен GitHub.

## Сервисы Яндекса

Почта, Календарь и Диск описаны на отдельной странице — [Сервисы Яндекса](./yandex-services.md).

## Субагенты совместимости

Субагенты совместимости могут требовать языковую модель, генератор изображений или дополнительные секреты. Их техническое описание находится на странице [Субагенты](../developer/subagents.md).

## Безопасность

- Не публикуйте ключи в снимках экрана, документации и журналах.
- Для общего сервера лучше выдавать пользователям отдельные ключи или ограниченные учётные записи.
- Перед демонстрацией коллегам проверьте, что в интерфейсе не видны секреты и лишние данные.
