# Модули

:::info[Документация текущего состояния]
Эта страница описывает текущую ветку `main` репозитория GigaAgent. Для стабильной документации PyPI-пакета `giga-agent==0.1.9` выберите версию **0.1.9 (PyPI)** в переключателе версий.
:::

Модуль — единица расширения GigaAgent. Он может добавлять маршруты, модели базы данных, миграции, инструменты, системные инструкции, секреты, промежуточные обработчики, подграфы и обработчики запуска.

Эта страница описывает стандартного агента из текущей ветки `main`. Для стабильного набора модулей PyPI-пакета `giga-agent==0.1.9` используйте версию документации **0.1.9 (PyPI)**.

## Контракт BaseModule

Основные поля и методы:

- `id` — уникальный идентификатор модуля;
- `label`, `description`, `icon` — сведения для интерфейса;
- `get_api_router()` — маршруты FastAPI;
- `get_models()` — модели SQLAlchemy для миграций;
- `_get_tools()` / `get_tools()` — инструменты модуля;
- `get_instructions()` — добавления к системной инструкции;
- `extend_task()` — расширение пользовательской задачи перед запуском;
- `get_secrets()` — сведения о нужных секретах;
- `get_middleware()` — промежуточные обработчики агента;
- `get_subgraphs()` — точки входа подграфов LangGraph;
- `is_enabled()` — доступность модуля для пользователя;
- `on_startup()` — обработчик запуска.

Если у модуля непустой `label`, обёртка `get_tools()` помечает пользовательские инструменты через `extras["module_id"]`, чтобы граф мог фильтровать инструменты отключённых модулей.

## Активные модули текущей ветки main

`giga_agent dev` в текущем репозитории загружает 21 модуль (порядок соответствует `GigaAgent.get_modules()`):

1. `AuthModule` — авторизация, пользователи и токены.
2. `ClarifyModule` — уточняющие вопросы: инструмент `ask_questions` показывает пользователю вопросы с вариантами ответа.
3. `ReplModule` — выполнение кода в изолированной среде.
4. `ImageModule` — генерация изображений.
5. `AnalyzeImagesModule` — анализ изображений.
6. `IOModule` — чтение, запись, редактирование и удаление файлов через инструменты агента.
7. `ProjectsModule` — [проекты](../user-guide/projects.md): маршруты управления проектами и подстановка инструкций проекта в системную инструкцию.
8. `ScraperModule` — чтение веб-страниц.
9. `SearchModule` — поиск.
10. `RagModule` — коллекции документов и поиск по ним.
11. `MemoryModule` — долговременная память и поиск по записям памяти; живёт в пакете `giga_agent/memory`.
12. `SkillsModule` — пользовательские навыки агента и чтение манифестов навыков.
13. `McpModule` — подключение внешних MCP-серверов и вызов их инструментов; включает каталог готовых серверов (`modules/mcp/catalog.json`).
14. `VKModule` — интеграция с VK.
15. `YandexDiskModule` — работа с файлами и папками на Яндекс.Диске.
16. `YandexMailModule` — чтение и отправка писем в Яндекс.Почте.
17. `YandexCalendarModule` — просмотр и создание событий в Яндекс.Календаре.
18. `WeatherModule` — прогноз погоды.
19. `DeepResearchModule` — глубокое исследование: план, поиск, чтение и отчёт с источниками.
20. `SchedulerModule` — задачи по расписанию: создание и отмена из чата, доставка результата в выбранный чат.
21. `SubAgentLegacyModule` — субагенты совместимости и их подграфы.

Модули внешних сервисов собраны в пакете `modules/integrations/`. Каждый из них несёт собственную авторизацию OAuth (`auth.py`, `provider.py`); пользователь включает такой сервис через каталог подключений в интерфейсе. Прежний `GitHubModule` удалён из репозитория: интеграция с GitHub выполняется через сервер GitHub из каталога MCP.

## Маршруты модулей

Если `get_api_router()` возвращает маршрутизатор, `BaseAgent` монтирует его под:

```text
{GIGA_AGENT_PREFIX_API}/{module.id}
```

При стандартном префиксе внутри приложения это `/agent/{module.id}`. При запуске через `giga_agent dev` внешний путь обычно:

```text
/api/agent/{module.id}
```

Примеры:

- `/api/agent/auth/token`;
- `/api/agent/rag/collections`;
- `/api/agent/memory/...`;
- `/api/agent/skills/...`.

Точный набор маршрутов зависит от того, какие модули возвращают `get_api_router()`, а набор инструментов — от настроенных провайдеров, секретов и прав пользователя.
