# GenUI: виджеты

Интерфейс выбирает виджет по маркеру `widget` в результате инструмента. Имя инструмента не участвует в маршрутизации, поэтому любой поставщик данных, вернувший нормализованный payload, отображается готовым виджетом без правок интерфейса.

## Реестр

Соответствия задаёт `front/src/components/widgets/registry.ts`:

| Маркер `widget` | Компонент | Что показывает |
|---|---|---|
| `mail_inbox` | `MailInbox` | Список писем; тело письма подгружается серверным маршрутом |
| `calendar_agenda` | `CalendarAgenda` | События ближайших дней |
| `calendar_month` | `MonthGrid` | Сетка месяца |
| `file_browser` | `FileBrowser` | Папка Яндекс.Диска с переходами и публикацией |
| `issue_board` | `BoardWidget` | Доска задач трекера |

Общие элементы (обёртка карточки, пустые состояния, типы payload) лежат в `front/src/components/widgets/kit/`.

## Серверная сторона

Инструмент собирает данные конструктором payload — `inbox_payload()`, `agenda_payload()`, `month_payload()`, `file_browser_payload()`, `board_payload()` — и возвращает их через `build_widget_tool_message()` (`core/agent/tool_results.py`). Payload дополняется отметкой `with_widget_note()` из `modules/integrations/widget_hint.py`: она просит агента не пересказывать содержимое виджета текстом. В канале Telegram отметка не ставится — там виджет не виден, и агент отвечает текстом.

## Как добавить виджет

1. Определите payload с новым маркером `widget` и соберите его в инструменте через `build_widget_tool_message()`.
2. Напишите компонент на общих элементах `kit/`.
3. Добавьте пару «маркер → компонент» в `WIDGET_KIND_REGISTRY`.

Новый поставщик данных для существующего виджета обходится без шагов 2 и 3 — достаточно нормализованного payload.

## Генеративная доска

Помимо статичных payload есть композиции: `emit_composed_board()` из `tracker_base.py` пушит группировку задач в `thread.values.ui` по имени `issue_board_composed`, и `BoardWidget` рисует её вживую по ходу выполнения. Переходы статусов задач идут через стандартные серверные маршруты `BaseTrackerModule`, минуя модель. Активных трекеров сейчас нет, контракт можно смотреть на модулях из `modules/integrations/` — подробнее в [Модулях-интеграциях](./integrations.md).
