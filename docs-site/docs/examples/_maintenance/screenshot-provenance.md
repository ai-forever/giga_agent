# Происхождение скриншотов примеров

Эта служебная страница не включена в боковое меню. Она фиксирует правила для будущего обновления галерей примеров.

## Правила

- Не пересоздавать скриншоты в рамках текущей задачи локализации и версионирования.
- Держать опубликованные скриншоты очищенными от секретов, внутренних ссылок, IP-адресов, имён хостов, идентификаторов потоков и персональных данных.
- Для текущих страниц `main` явно подписывать исторические изображения как иллюстрации похожего результата, а не как точную фиксацию текущего интерфейса.
- Для стабильных страниц PyPI не менять изображения без отдельной задачи и повторной проверки происхождения.
