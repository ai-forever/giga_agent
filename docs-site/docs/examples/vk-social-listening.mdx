# VK и social listening

Этот пример показывает, как использовать GigaAgent для анализа комментариев и пользовательских сигналов из VK: собрать сообщения, выделить темы, сгруппировать похожие комментарии и получить отчёт с рекомендациями.

## Что показывает пример

- подключение внешнего источника комментариев;
- очистку и подготовку текстов;
- тематическую группировку;
- визуализацию кластеров;
- summary для маркетинга, продукта или поддержки.

## Требования

- `giga-agent==0.1.9`;
- настроенный LLM connector;
- при работе с реальным VK — корректно настроенный доступ к VK-модулю;
- для воспроизводимого публичного примера лучше использовать заранее сохранённый CSV/JSON с обезличенными комментариями.

## Возможности GigaAgent

- VK integration;
- REPL/Python tools;
- embeddings/clustering через доступные инструменты окружения;
- генерация аналитического отчёта.

## Пример промпта

```text
Проанализируй комментарии пользователей из загруженного CSV.
Нужно:
1. очистить дубли и короткие нерелевантные сообщения;
2. выделить основные темы;
3. построить визуализацию кластеров;
4. перечислить боли пользователей;
5. дать рекомендации для команды продукта.
```

## Ожидаемый результат

- список тем или кластеров;
- количество комментариев в каждой группе;
- примеры типичных формулировок без раскрытия персональных данных;
- график или карта кластеров;
- приоритетные рекомендации.

## Как адаптировать

- Для production-сценария заранее определите правила хранения и обезличивания комментариев.
- Если нужны цитаты, ограничьте их длину и уберите имена, ссылки, телефоны и другие идентификаторы.
- Для стабильной документации используйте fixture-файл, а не живой VK-запрос.

## Ограничения

Автоматическая кластеризация помогает найти темы, но не заменяет ручную проверку. Для публичных отчётов проверяйте репрезентативность выборки.
