# Работа с презентациями

Этот пример показывает сценарий, где GigaAgent анализирует презентацию, предлагает улучшения и создаёт обновлённый `.pptx`-артефакт через Python-инструменты.

## Что показывает пример

- чтение структуры презентации;
- выявление слабых мест в сторителлинге;
- предложение новой структуры;
- программное изменение `.pptx`;
- создание файла результата.

## Требования

- запущена текущая сборка из ветки `main`;
- настроенное подключение языковой модели;
- доступна среда REPL/Python с библиотеками для работы с презентациями, например `python-pptx`;
- исходная презентация без закрытых данных.

## Возможности GigaAgent

- файлы и артефакты;
- инструменты REPL/Python;
- генерация и редактирование файлов;
- структурная критика документа.

## Пример промпта

```text
Я загрузил презентацию продукта. Улучши её для внешнего демо:
1. оцени текущую структуру;
2. предложи новую последовательность слайдов;
3. усили ценностное предложение;
4. создай обновлённый PPTX-файл;
5. кратко перечисли, что было изменено.
```

## Ожидаемый результат

- краткий аудит презентации;
- список изменений;
- обновлённый `.pptx` как артефакт;
- рекомендации, что проверить вручную перед публикацией.

## Как адаптировать

- Уточняйте аудиторию: инвесторы, разработчики, заказчики, внутренний митинг.
- Перед генерацией файла задайте визуальный стиль и ограничения бренда.
- Для публичных примеров используйте демонстрационную презентацию без коммерческой информации.

## Ограничения

Автоматическое редактирование презентаций хорошо подходит для черновика, но финальную вёрстку и брендовые требования стоит проверить вручную.
