# Фото → Lean Canvas

Этот пример показывает мультимодальный сценарий: пользователь загружает изображение продукта, а GigaAgent анализирует его и превращает наблюдения в структурированный бизнес-черновик.

## Что показывает пример

- анализ изображения;
- выделение свойств объекта;
- генерацию гипотез о пользователях и ценности;
- оформление результата в Lean Canvas.

## Требования

- запущена текущая сборка из ветки `main`;
- настроенное подключение языковой модели;
- доступна среда анализа изображений или модель с поддержкой изображений;
- изображение, права на использование которого понятны пользователю.

## Возможности GigaAgent

- AnalyzeImages;
- структурированный ответ;
- декомпозиция через субагенты совместимости для бизнес-анализа;
- генерация таблиц в Markdown.

## Пример промпта

```text
Я загрузил фото продукта. Проанализируй изображение и сделай Lean Canvas:
1. что это за продукт и чем он выделяется;
2. для какой аудитории он может быть полезен;
3. какие боли закрывает;
4. какие каналы продаж можно проверить;
5. какие риски у идеи.
```

## Ожидаемый результат

- описание визуальных признаков;
- таблица Lean Canvas;
- список гипотез для проверки;
- осторожные формулировки там, где агент делает предположения по изображению.

## Как адаптировать

- Добавьте контекст: рынок, страна, цена, канал продаж.
- Попросите отделить наблюдения по изображению от бизнес-гипотез.
- Для документации используйте собственные или синтетические изображения.

## Ограничения

Анализ изображения не гарантирует корректного понимания бренда, материалов, цены или спроса. Все бизнес-гипотезы требуют проверки.
