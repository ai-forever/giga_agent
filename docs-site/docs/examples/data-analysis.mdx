# Анализ таблиц и Excel-файлов

Этот пример показывает базовый сценарий: пользователь загружает CSV/XLSX-файл, задаёт вопросы на естественном языке, а GigaAgent строит сводки, таблицы и графики через Python-инструменты.

## Что показывает пример

- чтение табличного файла;
- подсчёт строк и проверка структуры данных;
- группировки по категориям, регионам или датам;
- расчёт долей и топ-N значений;
- построение графиков для отчёта.

## Требования

- запущена текущая сборка из ветки `main`;
- настроено подключение языковой модели;
- доступна изолированная среда REPL/Python для анализа;
- пользователь загружает CSV или XLSX без секретов и персональных данных.

## Возможности GigaAgent

- файлы и артефакты;
- инструменты REPL/Python;
- табличный анализ;
- генерация графиков и кратких выводов.

## Пример промпта

```text
Я загрузил Excel-файл с продажами. Проанализируй его:
1. Сколько всего строк и столбцов?
2. Какие регионы дают наибольшую долю продаж?
3. Построй топ-5 категорий по выручке.
4. Сформулируй 3 практических вывода для менеджера.
```

## Ожидаемый результат

GigaAgent должен:

- прочитать структуру файла;
- явно показать, какие столбцы использованы;
- построить сводную таблицу;
- вернуть график или несколько графиков;
- завершить ответ короткими бизнес-выводами.

## Как адаптировать

- Для больших файлов сначала попросите агента показать схему данных и пропуски.
- Для отчётов добавьте требуемый формат: Markdown, CSV, PNG-график или презентационный список выводов.
- Если файл содержит чувствительные данные, используйте обезличенную копию.

## Ограничения

Не стоит просить агента делать финансовые, юридические или медицинские выводы без экспертной проверки. Для публичной документации используйте синтетический датасет.
