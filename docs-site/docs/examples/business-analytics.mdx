# Бизнес-аналитика по CSV

Этот пример показывает, как GigaAgent помогает быстро разобраться в операционных данных: маршрутах, доставках, выручке, маржинальности и узких местах процесса.

## Что показывает пример

- загрузку CSV с бизнес-метриками;
- расчёт агрегатов по маршрутам, сегментам или периодам;
- поиск аномалий;
- построение нескольких графиков;
- формулирование управленческих рекомендаций.

## Требования

- запущена текущая сборка из ветки `main`;
- настроенное подключение языковой модели;
- доступна среда REPL/Python;
- CSV без секретов и персональных данных.

## Возможности GigaAgent

- файлы и артефакты;
- инструменты REPL/Python;
- первичный анализ данных;
- построение графиков;
- краткая сводка в формате бизнес-рекомендаций.

## Пример промпта

```text
Я загрузил CSV с доставками. Проанализируй маршруты:
1. найди самые прибыльные и самые проблемные направления;
2. сравни скорость доставки и выручку;
3. построй графики по ключевым метрикам;
4. предложи 5 действий для повышения маржинальности.
```

## Ожидаемый результат

- проверка качества данных;
- таблицы по маршрутам или категориям;
- 2–4 графика;
- список рисков и возможностей;
- практические рекомендации, привязанные к данным.

## Как адаптировать

- Заранее задайте бизнес-метрику успеха: прибыль, SLA, скорость, retention или cost-to-serve.
- Для повторяемых отчётов попросите агента сохранить notebook, скрипт или Markdown-отчёт.
- Если данные конфиденциальны, сделайте синтетическую выборку с такой же структурой.

## Ограничения

Агент может предложить гипотезы оптимизации, но решения по логистике или бюджету нужно проверять на реальных ограничениях бизнеса.
