# Примеры сценариев

Этот раздел показывает, как применять GigaAgent в типовых задачах: анализировать файлы, строить графики, работать с RAG, VK, изображениями и артефактами.

Страницы текущей версии описывают ветку `main`. Для примеров стабильного PyPI-пакета `giga-agent==0.1.9` используйте версию документации **0.1.9 (PyPI)**.

:::info Исторические скриншоты
В конце некоторых страниц есть галерея исторических прогонов. Это не PDF-журналы и не точные инструкции по старым версиям агента: скриншоты используются только как иллюстрации похожего результата. Текущий интерфейс и детали вывода могут отличаться.
:::

## Как подготовлены галереи

Галереи собираются из отдельных очищенных скриншотов старых прогонов. Исходные PDF не публикуются. Перед добавлением в документацию у скриншотов удаляются или перекрываются служебные области интерфейса, внутренние ссылки, идентификаторы потоков, IP-адреса, имена хостов и любые другие данные, которые могут раскрывать окружение запуска.

## Как читать примеры

Каждый пример содержит:

1. цель сценария;
2. минимальные требования к настройке;
3. возможности GigaAgent, которые используются;
4. пример запроса;
5. ожидаемый результат;
6. ограничения и советы по адаптации;
7. галерею исторических скриншотов, если для сценария есть безопасные иллюстрации.
