# Обзор GigaAgent

GigaAgent — модульный агент с серверной частью на FastAPI, графом выполнения LangGraph и встроенным веб-интерфейсом. Команда `giga_agent dev` поднимает локальный сервер на порту `9090` и отдаёт и программный интерфейс, и веб-интерфейс.

## Основные части

| Часть | Назначение |
|---|---|
| Python-пакет `giga_agent` | Команда `giga_agent`, серверная часть, граф выполнения, модули и миграции. |
| Веб-интерфейс | Чат, настройки, коллекции RAG, память, администрирование и работа с файлами. |
| Граф выполнения | Управляет ходом ответа агента, вызовами инструментов и потоковой выдачей сообщений. |
| Модули | Подключают возможности: авторизацию, RAG, память, поиск, изображения, файловые операции, навыки, глубокое исследование и интеграции. |
| Провайдеры | Языковые модели, векторные представления, поиск, генерация изображений и изолированная среда. |

## Что умеет агент

Доступность возможностей зависит от настроек пользователя. После запуска сразу доступны вход в интерфейс и базовая настройка, но для содержательной работы нужно подключить языковую модель.

Проверенные группы возможностей:

- чат с потоковой выдачей ответа и уточняющими вопросами агента;
- загрузка файлов и отображение результатов инструментов, в том числе [виджетами](./user-guide/widgets.md);
- файловые операции через `IOModule`;
- RAG по коллекциям документов при настроенных векторных представлениях;
- долговременная память через `MemoryModule`;
- навыки агента через `SkillsModule`;
- глубокое исследование через `DeepResearchModule` при настроенных модели и поиске;
- генерация и анализ изображений при настроенных провайдерах;
- выполнение кода и команд при настроенной изолированной среде;
- внешние сервисы через [каталог коннекторов](./user-guide/connectors.md): [серверы MCP](./user-guide/connectors.md#каталог), [Яндекс.Почта, Календарь и Диск](./user-guide/yandex-services.md), [VK](./user-guide/external-services.md#vk-и-погода), [GitHub](./user-guide/external-services.md#github);
- [задачи по расписанию](./user-guide/scheduler.md) с доставкой результата в [канал Telegram](./user-guide/channels.md);
- [погода](./user-guide/external-services.md#vk-и-погода), [поиск](./user-guide/external-services.md#поиск-в-интернете) и [готовые субагенты прежних версий](./user-guide/external-services.md#готовые-субагенты) (лендинг, презентация, мем и другие) при наличии нужных секретов.

Подробнее см. [Возможности и требования](./user-guide/capabilities.md).

## С чего начать

1. Установите и запустите текущую сборку из репозитория: [Быстрый старт локально](./quickstart/local.md).
2. Настройте языковую модель и отправьте первое сообщение: [Первый чат](./quickstart/first-chat.md).
3. Разберитесь, какие возможности требуют дополнительных настроек: [Возможности и требования](./user-guide/capabilities.md).
4. Если показываете сервер коллегам, прочитайте [Совместный сервер](./operations/shared-server.md).
5. Для архитектурных деталей перейдите к разделу [Архитектура](./developer/architecture.md).
