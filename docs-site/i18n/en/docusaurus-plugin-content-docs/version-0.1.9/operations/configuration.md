# Configuration

Important variables in version 0.1.9 include `GIGA_AGENT_PREFIX_API`, `GIGA_AGENT_RUNTIME`, `GIGA_AGENT_SECRET_KEY`, `GIGA_AGENT_TOOL_MAX_SIZE`, `GIGA_AGENT_QDRANT_POOL_SIZE`, `GIGA_AGENT_SCRAPER_TOTAL_CONCURRENCY`, `GIGA_AGENT_MEM0_QDRANT_ENSURE_CACHE`, and `GIGA_AGENT_LANGGRAPH_DEV_PORT`.

Use `/api/agent/...` from the browser when running through `giga_agent dev`, although internal routes start with `/agent/...`.
