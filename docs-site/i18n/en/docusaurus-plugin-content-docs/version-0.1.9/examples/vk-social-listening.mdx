# VK and social listening

This scenario shows how GigaAgent can analyze comments and user signals: clean texts, group similar comments, find themes, and prepare recommendations.

## Requirements

- Running GigaAgent.
- Configured language model connector.
- VK access for live data, or an anonymized CSV/JSON file for reproducible public examples.

## Prompt example

```text
Analyze comments from the uploaded CSV: remove duplicates, find themes, visualize clusters, list user pains, and recommend actions for the product team.
```

## Expected result

The result should include clusters, counts, anonymized examples, a chart or map, and prioritized recommendations.
