# Files and artifacts

Files let users provide source material to the agent. Artifacts are generated outputs such as tables, charts, documents, images, or edited files.

## Typical flow

1. Upload a file in the UI.
2. Ask the agent to inspect, summarize, transform, or use it in a tool call.
3. Review which file or artifact the agent produced.
4. Download only outputs that you have verified.

## Safety

Do not upload secrets, credentials, private keys, or raw personal data unless the deployment is authorized for that data. For public examples, use synthetic files.
