# Обзор GigaAgent

Эта документация описывает `giga-agent==0.1.9`. Пакет устанавливается как `giga-agent`, команда запуска называется `giga_agent`, а сервер разработки отдаёт и программный интерфейс, и встроенный веб-интерфейс.

Отдельная сборка веб-интерфейса не требуется: команда `giga_agent dev` запускает локальный сервер на порту `9090`.

## Основные части

| Часть | Назначение |
|---|---|
| Python-пакет `giga_agent` | Команда `giga_agent`, серверная часть, граф выполнения, модули и миграции. |
| Веб-интерфейс | Чат, настройки, коллекции RAG, память, администрирование и работа с файлами. |
| Граф выполнения | Управляет ходом ответа агента, вызовами инструментов и потоковой выдачей сообщений. |
| Модули | Подключают возможности: авторизацию, RAG, память, поиск, изображения, песочницу, интеграции. |
| Провайдеры | Языковые модели, векторные представления, поиск, генерация изображений и изолированная среда. |

## Что умеет агент

Доступность возможностей зависит от настроек пользователя. После установки сразу доступны вход в интерфейс и базовая настройка, но для содержательной работы нужно подключить языковую модель.

Проверенные группы возможностей:

- чат с потоковой выдачей ответа;
- загрузка файлов и отображение результатов инструментов;
- RAG по коллекциям документов при настроенных векторных представлениях;
- долговременная память при настроенных векторных представлениях;
- генерация и анализ изображений при настроенных провайдерах;
- выполнение кода и команд при настроенной изолированной среде;
- интеграции GitHub, VK, погоды, поиска, а также готовые субагенты прежних версий (лендинг, презентация, мем и другие) при наличии нужных секретов.

Подробнее см. [Возможности и требования](./user-guide/capabilities.md).
