# Модули

Модуль — единица расширения GigaAgent. Он может добавлять маршруты, модели базы данных, миграции, инструменты, системные инструкции, секреты, промежуточные обработчики, подграфы и обработчики запуска.

Эта страница описывает стандартного агента из `giga-agent==0.1.9`.

## Контракт BaseModule

Основные поля и методы:

- `id` — уникальный идентификатор модуля;
- `label`, `description`, `icon` — сведения для интерфейса;
- `get_api_router()` — маршруты FastAPI;
- `get_models()` — модели SQLAlchemy для миграций;
- `_get_tools()` / `get_tools()` — инструменты модуля;
- `get_instructions()` — добавления к системной инструкции;
- `extend_task()` — расширение пользовательской задачи перед запуском;
- `get_secrets()` — сведения о нужных секретах;
- `get_middleware()` — промежуточные обработчики агента;
- `get_subgraphs()` — точки входа подграфов LangGraph;
- `is_enabled()` — доступность модуля для пользователя;
- `on_startup()` — обработчик запуска.

Если у модуля непустой `label`, обёртка `get_tools()` помечает пользовательские инструменты через `extras["module_id"]`, чтобы граф мог фильтровать инструменты отключённых модулей.

## Активные модули версии 0.1.9

`giga_agent dev` загружает 12 модулей:

1. `AuthModule` — авторизация, пользователи и токены.
2. `ReplModule` — инструменты выполнения кода через изолированную среду.
3. `ImageModule` — генерация изображений.
4. `AnalyzeImagesModule` — анализ изображений.
5. `ScraperModule` — чтение веб-страниц.
6. `SearchModule` — поиск.
7. `RagModule` — коллекции документов и поиск по ним.
8. `MemZeroModule` (`mem_zero_memory`) — долговременная память через Mem0.
9. `GitHubModule` — интеграция с GitHub.
10. `VKModule` — интеграция с VK.
11. `WeatherModule` — прогноз погоды.
12. `SubAgentLegacyModule` — субагенты совместимости и их подграфы.

## Маршруты модулей

Если `get_api_router()` возвращает маршрутизатор, `BaseAgent` монтирует его под:

```text
{GIGA_AGENT_PREFIX_API}/{module.id}
```

При стандартном префиксе внутри приложения это `/agent/{module.id}`. При запуске через `giga_agent dev` внешний путь обычно:

```text
/api/agent/{module.id}
```

Примеры:

- `/api/agent/auth/token`;
- `/api/agent/rag/collections`;
- `/api/agent/files`;
- `/api/agent/mem_zero_memory/memories`.
