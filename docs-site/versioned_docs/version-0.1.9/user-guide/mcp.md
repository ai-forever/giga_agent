# MCP-инструменты

MCP-инструменты позволяют передать в чат дополнительные действия из внешних подключений интерфейса. Для пользователя это выглядит как расширенный набор инструментов, доступный в конкретном диалоге или сообщении.

## Как пользоваться

1. Подключите или выберите MCP-инструменты в интерфейсе, если такая интеграция доступна.
2. Отправьте сообщение в чат.
3. Агент сможет использовать переданные инструменты вместе с остальными доступными возможностями.

## Важные ограничения

- Набор MCP-инструментов может отличаться между диалогами и сообщениями.
- Если интерфейс не передал инструмент, серверная часть не сможет вызвать его в этом ходе диалога.
- Права пользователя, ограничения изолированной среды и общие правила выполнения инструментов остаются на стороне серверной части.

Для разработчиков: агент получает MCP-инструменты через состояние диалога, а не через отдельный встроенный модуль. Подробнее см. [Инструменты](../developer/tools.md).
