# Проекты

:::info[Документация стабильного релиза PyPI]
Эта страница описывает опубликованный PyPI-пакет `giga-agent==0.1.9`. Для актуального состояния репозитория переключитесь на версию **main**.
:::

В пакете `giga-agent==0.1.9` проектов нет — эта возможность появилась позже, в ветке `main`.

Описание проектов (группировка диалогов с общими инструкциями и отдельной базой знаний) доступно в документации версии **main** — переключите версию в выпадающем списке версий вверху страницы.
