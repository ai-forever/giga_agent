# Изображения

GigaAgent разделяет генерацию изображений и анализ изображений. Обе возможности требуют отдельных настроек.

## Генерация

Для генерации нужен настроенный провайдер изображений. В настройках доступны операции управления такими провайдерами: создание, просмотр, обновление и удаление.

Если провайдер не настроен или недоступен пользователю, агент не должен обещать генерацию картинки.

## Анализ изображений

Анализ изображений доступен только при выбранной модели, которая умеет работать с изображениями. Если такая модель не настроена, агент не сможет корректно описать или разобрать картинку.

## Практический порядок

1. Настройте провайдер изображений или модель с поддержкой изображений.
2. Для анализа приложите изображение к сообщению.
3. Для генерации сформулируйте задачу и убедитесь, что у пользователя есть доступ к провайдеру.
4. Проверьте результат как обычное вложение или результат инструмента.
