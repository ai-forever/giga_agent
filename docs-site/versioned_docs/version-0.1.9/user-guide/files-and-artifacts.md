# Работа с файлами

GigaAgent поддерживает загрузку файлов в чат и работу с файлами через слой хранения и изолированную среду. Важно различать:

- **загруженные файлы** — файлы, отправленные пользователем через интерфейс или программный интерфейс;
- **пути изолированной среды** — пути внутри среды выполнения кода;
- **результаты инструментов** — текст, изображение, аудио, видео, график или файл, созданный агентом.

## Маршруты файлов

Для `giga_agent dev` внешний префикс — `/api/agent`, поэтому основные маршруты доступны под `/api/agent/files`:

- `POST /upload` — загрузить файл; поддерживает `thread_id` и `file_type` в форме;
- `GET /` — список файлов, доступных пользователю;
- `GET /{file_id}/content` — получить содержимое файла;
- `GET /content/by-path?path=...` — получить содержимое по пути изолированной среды;
- `DELETE /{file_id}` — удалить файл.

При обычной работе с интерфейсом прямые HTTP-запросы не нужны.

## Работа с файлами из чата

Файлы можно прикладывать к сообщению. Агент увидит вложения в контексте запроса, а результаты инструментов могут вернуться как вложения или отображаемые артефакты.

Для задач с кодом и командами настройте изолированную среду. Путь на машине, путь внутри изолированной среды и путь в хранилище файлов — разные пространства.

## Практические советы

- Прикладывайте файлы прямо к сообщению, если хотите, чтобы агент использовал их в задаче.
- Для больших документов используйте RAG-коллекции, а не ручное копирование текста в чат.
- Если файл не открывается, проверьте права и настройки изолированной среды.
