# Диагностика

Ниже — частые симптомы и проверки.

## Сервер не стартует: секретный ключ

Симптом: запуск завершается сообщением, что `GIGA_AGENT_SECRET_KEY` не задан.

Причина: серверная часть ожидает секретный ключ для авторизации. Для общего сервера задавайте его явно. При локальном запуске через `giga_agent dev` команда может подготовить ключ автоматически.

Проверка без вывода самого секрета:

```bash
test -n "$GIGA_AGENT_SECRET_KEY" && echo "GIGA_AGENT_SECRET_KEY задан"
```

## Чат открывается, но сообщение не выполняется

Проверьте:

1. У пользователя выбрана языковая модель.
2. Коннектор модели сохранён и содержит корректные параметры доступа.
3. Сервер видит правильный адрес `/api`.
4. Для выбранного инструмента настроен нужный провайдер: изолированная среда, векторные представления, поиск или генерация изображений.
5. У пользователя есть права на файл, коллекцию или другой ресурс.

## RAG не ищет по документам

Проверьте:

- у пользователя выбрана модель векторных представлений;
- Qdrant доступен, если используется как хранилище векторов;
- коллекция создана и документы загружены;
- пользователь имеет право читать коллекцию;
- выбранные документы относятся к активной коллекции чата.

## Docker Compose поднялся, но интерфейс не открывается

Проверьте состояние служб:

```bash
docker compose ps
```

Ожидаемый вход через nginx:

```text
http://localhost:8123
```

Если серверная часть не стартует, проверьте `GIGA_AGENT_SECRET_KEY`, адрес базы данных, доступность PostgreSQL, Redis, Qdrant и настройки Docker.

## Интерфейс не обращается к серверу

При локальном запуске `giga_agent dev` сервер обычно слушает `9090`, а программный интерфейс доступен под `/api`. Проверьте `/app-config.js` и убедитесь, что там указан ожидаемый адрес.
