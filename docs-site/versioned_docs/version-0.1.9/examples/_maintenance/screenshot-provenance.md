# Происхождение скриншотов примеров

Эта служебная страница не включена в боковое меню. Она фиксирует правила для будущего обновления галерей примеров стабильной документации PyPI.

## Правила

- Не добавлять скриншоты с видимыми учётными данными, токенами, адресами баз данных, веб-хуками, внутренними именами хостов, идентификаторами потоков, IP-адресами, персональными или закрытыми корпоративными данными.
- Перед коммитом скрывать служебные области интерфейса, ссылки, идентификаторы потоков, имена хостов, IP-адреса, идентификаторы пользователей и другие детали конкретного окружения.
- Держать страницы примеров согласованными с опубликованной версией PyPI `giga-agent==0.1.9`, если страница явно не помечает возможность как относящуюся к текущей ветке main.
- Не пересоздавать скриншоты без отдельной задачи и повторной проверки происхождения.
