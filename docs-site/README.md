# GigaAgent docs-site

Docusaurus-сайт с русскоязычной документацией GigaAgent.

## Commands

```bash
npm install
npm run start
npm run build
npm run typecheck
```

Контент пишется code-first: факты проверяются по исходному коду, конфигам и сборке, а старые markdown-файлы используются только как подсказки.
