# Правила для backend-тестов

- Unit-тест должен проверять только относящееся к нему поведение. Не запускай реальные
  периодические сервисы, sweepers, scheduler, фоновые workers, внешние процессы или
  SQLite-сессии, если их lifecycle не является предметом теста: замокай или отключи их.
- Lifecycle фоновых сервисов проверяй отдельными специализированными тестами.
- Не используй реальные ожидания (`sleep`) для синхронизации тестов; применяй mocks,
  events или контролируемые часы.
- Общая test-fixture направляет `GIGA_AGENT_PROJECT_ROOT` в изолированную временную
  `.giga_agent`; никогда не используй рабочую `backend/.giga_agent` или её `local.db`.
- Для запуска backend-тестов используй `uv run pytest tests/...`; не запускай `uv run pytest`
  без пути, так как он может собрать вспомогательные скрипты вне test suite.
